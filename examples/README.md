# Examples — index

Case studies referenced by `SKILL.md`. Read one before planning a page of that shape; do not read all of them.

**All products, companies, and data in these examples are fictional.** They exist to make a compositional argument concrete, not to document a real product.

## Composition grammar in action (`composition/`)

One file per grammar. Each shows the layout, the attention budget, and why that grammar fits the problem.

| File | Grammar | Use it when |
|---|---|---|
| `dominant-supporting.md` | Dominant + Supporting | One thing matters, everything else supports it |
| `asymmetric-split.md` | Asymmetric Split | Two unequal regions, deliberately unbalanced |
| `editorial-stack.md` | Editorial Stack | Content-led page, typography as structure |
| `open-field.md` | Open Field + Data Cluster | Mostly whitespace with a dense cluster in it |
| `dense-utility.md` | Dense Utility Rail | Pro tool where density is the feature |

The remaining two grammars — Full-width Anchor and Layered Information Plane — are defined in `references/general/composition-grammar.md` with wireframes.

## Contributing an example

- Fictional subject, or a real product discussed at the level of compositional decisions only
- Must include the attention budget — a composition example without one teaches nothing
- Must state *why that grammar*, not just what it looks like
- Prefer fixing a real defect over inventing a pretty page
